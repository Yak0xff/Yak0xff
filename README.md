## 小故事 · About（30 秒）

我喜欢把产品想法当做小游戏来做：把核心体验当成关卡，先把关卡做透，再扩展成一个系统。第一个观影记录 App 让我意识到：用户真正记住的是「顺手」与「乐趣」，不是功能堆砌。现在我把这种“可玩化”的思路带到每个项目里。
